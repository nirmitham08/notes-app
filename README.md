# React Notes App

A simple and interactive Notes App built using React.js.

## Features
- Add new notes
- Delete existing notes
- Save notes using browser localStorage
- Notes remain saved after refreshing the page
- Dark Mode and Light Mode toggle
- Browser tab displays the total number of notes
- Prevents empty notes from being added
- Uses React Hooks and Context API

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Used
- useState
- useEffect
- useContext
- createContext
- Props
- Component-based architecture

## How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.
